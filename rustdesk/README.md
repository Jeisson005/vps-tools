# 🖥️ RustDesk Self-Hosted Server & Host Client

Self-hosted **RustDesk Server** (`hbbs` + `hbbr`) for secure, low-latency, end-to-end encrypted remote desktop, plus an optional **host client** that exposes this VPS desktop (`DISPLAY=:1`) to any RustDesk app pointed at your server.

> The old containerized web desktop (`desk.*`, `rustdesk-web`) was retired: it duplicated the host KasmVNC desktop while costing ~450MB + ~14% idle CPU. Browser access lives in `desktop/` (KasmVNC); native-app access uses the host client below.

---

## 🎯 Architecture & Ports

RustDesk server requires the following ports open on your firewall (`ufw`):
* `21115/tcp`: NAT type test
* `21116/tcp`: TCP hole-punching / ID registration
* `21116/udp`: UDP heartbeat / peer discovery
* `21117/tcp`: Encrypted relay service
* `21118/tcp`: WebSocket signaling for browser-based clients (via nginx `rustdesk.*`/ws/id)
* `21119/tcp`: WebSocket relay for browser-based clients (via nginx `rustdesk.*`/ws/relay)

```bash
# Allow in UFW Firewall:
sudo ufw allow 21115:21119/tcp comment "RustDesk Server TCP (hbbs/hbbr)"
sudo ufw allow 21116/udp comment "RustDesk Server UDP (hbbs discovery)"
sudo ufw reload
```

DNS: `RUSTDESK_DOMAIN` (e.g. `rustdesk.jeisson.top`) must resolve to the VPS (raw TCP, not proxied). The nginx vhost for that name only serves `/ws/*` endpoints; there is no web desktop anymore.

## 🚀 Server Setup

### 1. Configure Environment
```bash
cp .env.example .env
chmod 600 .env
nano .env
```
* `RUSTDESK_DOMAIN=rustdesk.jeisson.top`
* `RUSTDESK_KEY=` (blank = auto-generated by hbbs)

### 2. Start Services
```bash
./scripts/start.sh
```

### 3. Retrieve Server Public Key
```bash
./scripts/status.sh
# Output will display: 🔑 Server Public Key: <PUB_KEY>
```

## 💻 Host Client (control THIS VPS from your devices)

Installs the RustDesk client pointed at your own server, capturing desktop `DISPLAY=:1` (the same KasmVNC/XFCE session the web and the AI agent use):

```bash
sudo bash scripts/install_host_client.sh
```

The script installs the pinned `.deb`, writes `~/.config/rustdesk/RustDesk2.toml` (rendezvous `127.0.0.1:21116`, relay + pinned server key), sets the permanent password (`RUSTDESK_HOST_PASSWORD` in `.env`, auto-generated if empty), and enables `rustdesk-host@<user>.service`. It prints the numeric **Host ID** at the end (or run `rustdesk --get-id` later).

### Client Configuration (laptop / phone apps)
1. Open **Settings** → **Network** / **ID/Relay Server**.
2. Set:
   * **ID Server:** `rustdesk.jeisson.top`
   * **Relay Server:** `rustdesk.jeisson.top`
   * **Key:** `<YOUR_PUBLIC_KEY>`
3. Connect to the **Host ID** with the host password!

## 🛑 Stop / Status

```bash
./scripts/stop.sh    # stops hbbs + hbbr (server)
./scripts/status.sh  # container status + server public key
sudo systemctl status rustdesk-host@jeisson  # host client
```
